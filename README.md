# Supervivencia submarina — juego de texto en Java

Aventura interactiva por terminal en la que el jugador explora zonas submarinas, administra oxígeno e inventario y fabrica mejoras para sobrevivir y reparar su nave.

## Contenido técnico

- Modelado orientado a objetos de jugador, zonas, nave, oxígeno e ítems.
- Menús e interacción por consola.
- Recetas de fabricación para herramientas, equipo y reparaciones.

## Requisitos y ejecución

Se requiere JDK 17 o posterior y GNU Make.

```bash
make run
```

El juego solicita el nombre del personaje e instrucciones durante la partida. Para borrar los archivos generados por Make:

```bash
make clean
```

## Alcance

Trabajo académico de programación. La ejecución es por terminal y el progreso se mantiene durante la sesión; este repositorio no incluye guardado persistente.
